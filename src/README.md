
# React em Prática — Guia Interativo

## Sobre
Projeto desenvolvido para a avaliação prática de recuperação
do SENAI Santa Catarina.

## Objetivo
Apresentar oito conteúdos fundamentais de desenvolvimento web
com explicações, exemplos e correções de erros comuns.

## Funcionalidades
- Oito cards educativos.
- Marcação de conteúdos revisados.
- Contador de progresso.
- Cadastro e remoção de dúvidas.
- Validação com trim().
- Layout responsivo.

## Tecnologias
- React
- JavaScript
- JSX
- CSS
- Vite
- Git e GitHub

## Como executar

npm install
npm run dev

## Gerar versão de produção

npm run build
